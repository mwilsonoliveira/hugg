# Setup do Hugg

A arquitetura atual usa Next.js na Vercel para frontend e API, Turso/libSQL para dados e Vercel Blob para fotos.

Para preparar o ambiente local, siga a seção [Desenvolvimento](README.md#desenvolvimento) do README. Para configurar Production/Preview e migrar o banco antigo, use [docs/deployment.md](docs/deployment.md).

O documento de arquitetura mantido pelos agentes está em [docs/context/architecture.md](docs/context/architecture.md).
